# NovaBank

Proyecto académico desarrollado para la materia Plataformas de Desarrollo.

## Tecnologías

- React
- Vite
- React Router
- Lucide React
- CSS

## Funcionalidades actuales

- Pantalla Login
- Pantalla Registro
- Landing Page
- Dashboard Cliente
- Dashboard Administrador
- Tarjetas
- Inversiones
- Compra de dólar
- Transferencias entre clientes
- Contactos, favoritos y referencias para transferencias
- Registro local de movimientos y saldos
